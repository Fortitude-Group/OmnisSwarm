# OmnisSwarm Phase 2 (Recorder) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record what a Claude Code session's agents actually do (spawns, tool calls, model usage, messages, turn ends, session context and cost) into the OmnisSwarm event log, through a mod that hands every event to the plugin's own MCP server.

**Architecture:** A mod (`src/mod/`, loaded from `hooks/hooks.json`) observes engine events and turns each into a small event body using pure, Node-free builders. It sends each one, fire and forget, with `$.mcp.call` to a new internal server tool, `omnis_record`, which validates it, stamps `v`, `swarm` and `src: recorder`, creates the implicit session swarm when needed and appends it with `core/log.ts`. A `tool.check` guard keeps the model and other plugins off the internal tools. The server also learns its Claude Code session id from those calls, stamps it on the swarms it starts, and uses it after a restart to know which swarm is its own.

**Tech Stack:** Node 24 (type stripping, `node:test`), TypeScript 7 for type-checking only, Claude Code 2.1.306 function hooks (mods) and its `claude plugin validate` / `claude plugin test` kit.

**Spec:** `docs/superpowers/specs/2026-10-21-omnisswarm-design.md` (sections 4-9, 11, 12, 14, 15). Mod API facts: `docs/spikes/2026-10-21-mod-api.md`.

## Global Constraints

- Node `>=24`, no build step, no runtime npm dependencies. Dev dependencies stay `typescript ^7.0.2` and `@types/node ^24`.
- Erasable TypeScript only (no `enum`, `namespace`, parameter properties). Relative imports end in `.ts`. Type-only imports use `import type`.
- No file over 500 lines. The one exception is the vendored engine declaration `types/claude-code/index.d.ts` (generated by Claude Code, ~22,000 lines, never edited by hand).
- Mod code is everything under `src/mod/` plus the mod-safe core files `src/core/events.ts`, `fold.ts`, `prices.ts`, `stats.ts` and (new) `recording.ts`. It imports nothing from `node:*`, uses no Node globals (`Buffer`, `process`, `require`, `module`, `fetch`, `queueMicrotask`), and imports only its own files by relative path and `'claude-code'`.
- Pure mod files that `node --test` covers (`src/mod/record-events.ts`, `src/mod/outbox.ts`, `src/core/recording.ts`) import nothing from `'claude-code'`, not even types, because `tsconfig.json` can't resolve that module.
- In a mod, `$` is passed only to functions declared at the top level of a file or imported from the plugin's own files.
- Mod timestamps use `Date.now()`. `$.mcp.call` arguments are plain cloneable data (no Promise, no function).
- The recorder is observe-only: every hook calls `next(e)` exactly once and returns its result unchanged, even when its own work throws. It never awaits `$.mcp.call` before `next`.
- At most 64 `omnis_record` calls in flight per session (`MAX_IN_FLIGHT`). Past that an event is dropped and counted, and the count rides on the next call that gets through as `dropped`.
- Internal tools: `omnis_record` (this phase) and `omnis_feed` (phase 3). Their full names match `/^mcp__plugin_.+__omnis_(record|feed)$/`.
- Log limits (from phase 1, unchanged): line 2048 bytes; summary 200, subject 80, description 120, preview 80, reason 80 characters. Agent ids and names match `^[A-Za-z0-9._-]{1,64}$`.
- Never store full prompts, tool output or file contents. Protocol message summaries carry `[<type>]` and `approve: yes/no` only, never `reason` or `feedback`.
- Gate before every commit: `npm run check` is green. From Task 1 on, that is both typechecks, `npm test`, then `npm run test:mod` (`claude plugin validate .` and `claude plugin test` on a staged copy). The `claude` CLI (2.1.306) must be on PATH; without it `test:mod` says it skipped.
- Commit as `Fortitude Omnis <dev@fortitude-omnis.group>`, in plain developer English (British spelling). No `Co-Authored-By`, no "Generated with" line, no AI attribution of any kind.
- Windows is the dev platform. Every command below works in Git Bash and PowerShell.
- Shared files have one owner, the integrator, and are only edited in Task 1 and Task 8: `package.json`, `tsconfig.json`, `tsconfig.mod.json`, `.gitignore`, `.claude-plugin/plugin.json`, `hooks/hooks.json`, `src/mod/register.ts`, `types/index.d.ts`, `src/mcp/registry.ts`, `tests/core/mod-safe.test.ts`, `tests/e2e/mcp-server.test.ts`.

## Facts this plan relies on (verified 2026-10-21, Claude Code 2.1.306)

From the spike (rounds 1-3): event shapes for `agent.spawn`, `tool.call`, `turn.step`, `turn.complete`, `session.send`, `session.measure`, `session.start`; `$.session.id()`; `$.agent.list()`; the mod → `$.mcp.call` → server channel; the origin guard (`next.origin` is `{ plugin: 'engine', tier: 'core' }` for the model, `{ plugin: '<ours>', tier: 'user' }` for our own calls); `$.mcp.call` raising `tool.call`/`tool.check` in a real session; parent-folder imports.

Probed by the planner for this plan, in a scratch plugin (`claude plugin validate`, `claude plugin test`, `tsc`):

1. `hooks/hooks.json` names one module, and `{"modules":["../src/mod/register.ts"]}` validates and loads under `claude plugin test`. A path that leaves the plugin folder is refused (`The module path leaves the plugin directory`).
2. `claude plugin test <dir>` runs every `*.test.ts` under `<dir>` except `node_modules`, and `<dir>` must be the plugin root (it needs `hooks/hooks.json`). On this repo it would load `tests/**/*.test.ts` and fail: `cannot import "node:test" ... a hooks module imports its own files by relative path and "claude-code", nothing else`. Hence `scripts/test-mod.ts` stages a copy without `tests/`.
3. In the kit, the test's `on('<noun>.<method>', ...)` answers a plugin's `$` call with `{ value }` (`session.id`, `mcp.connect`, `mcp.call`, `agent.list`), and an event with its own result (`session.start` must answer `{ cwd }`, `tool.call` `{ result }`, `agent.spawn` `{ model, agentId }`). `$.tool.call`, `$.agent.spawn`, `$.turn.step` (an async generator; `stream.result` holds the result), `$.tool.check` and `$.tool.describe` raise the plugin's hooks. Fire-and-forget `$.mcp.call`s had all reached the test's hook by the time the next awaited `$` call returned.
4. In the kit, a plugin's `$.mcp.call` goes straight to the test's `mcp.call` hook and does **not** raise `tool.check` or `tool.call` (a real session does, spike A1d). So the guard's allow-own-origin path can't be shown in the kit; it was verified live in the spike and is re-checked live in Task 9.
5. A guard hook saw `next.origin.plugin` = `engine` for the test's own `$.tool.check`, and `intruder` for an inline plugin's `$.tool.check` query, and denied both.
6. A `$.state` contract must declare each key inline: `declare module 'claude-code' { interface PluginState { 'omnis-swarm': { seen: string[]; dropped: number } } }`. `export {}` in the contract is refused (`a contract exports types and nothing else`), and keys hidden behind a named type alias are reported as `not declared`.
7. `tsc -p tsconfig.mod.json` with `"types": []`, `"lib": ["es2024"]` and the engine declaration included passes on the mod-safe core files and fails a mod file using `process` or `Buffer` (`TS2591: Cannot find name 'process'`). The engine declaration itself declares the mod globals (`TextEncoder`, `structuredClone`, `URL`, `crypto`, `atob`/`btoa`, `performance`, `AbortController`), so no extra ambient file is needed (spec section 12 asked for one; this is the same thing, supplied by the engine).
8. `spawnSync('claude', ['--version'])` from Node works on this machine (`claude.exe` in `~/.local/bin`).

Not verified, and checked live in Task 9: whether `$.mcp.call` raises classic `PreToolUse` command hooks; whether a protocol (object) `SendMessage` raises `session.send` (the engine declaration says `session.send` is for plain-text messages only).

- [ ] **Step 4: Write the contract**

Create `src/core/recording.ts`:

```ts
/** What the recorder mod sends to the server's internal omnis_record tool, and the rule that guards it. Pure and mod-safe: no Node. */
import type { EventData } from './events.ts'

/** The only event types omnis_record accepts. The server writes the swarm, memory and task events itself. */
export const RECORDER_TYPES = ['agent.started', 'agent.finished', 'agent.usage', 'agent.tool', 'message.sent', 'session.measure'] as const
export type RecorderType = (typeof RECORDER_TYPES)[number]

export const RECORD_TOOL = 'omnis_record'

/** The server's key under mcpServers in plugin.json, as $.mcp.connect takes it. */
export const SERVER_KEY = 'omnis-swarm'

/** Past this many omnis_record calls in flight, the recorder drops events and counts them (spec section 6). */
export const MAX_IN_FLIGHT = 64

/** A Claude Code session id, as $.session.id() gives it (the transcript file's name, a UUID). */
export const SESSION_ID = /^[A-Za-z0-9][A-Za-z0-9-]{7,63}$/

/**
 * The internal tools by full name, `mcp__plugin_<plugin>_<server>__omnis_record` (or `__omnis_feed`).
 * The plugin segment is left open so a marketplace install, which may rename it, is still covered.
 */
export const INTERNAL_TOOL = /^mcp__plugin_.+__omnis_(record|feed)$/

/** An internal tool may be called only from this plugin's own hooks. Every other tool is not the guard's business. */
export function guardVerdict(tool: string, origin: string, self: string): 'pass' | 'deny' {
  return INTERNAL_TOOL.test(tool) && origin !== self ? 'deny' : 'pass'
}

export type RecordBody<K extends RecorderType = RecorderType> = {
  [T in K]: { type: T; agent?: string; data: EventData[T] }
}[K]

/** One omnis_record call. `ts` is the mod's clock at hook time; `dropped` counts events lost since the last call that got through. */
export type RecordArgs = RecordBody & { sessionId: string; ts: string; dropped?: number }
```

```ts
/**
 * Turns Claude Code hook inputs into the event bodies the recorder sends to omnis_record.
 * Pure and mod-safe, and it imports nothing from 'claude-code', so node:test covers it too.
 */
import { LIMITS, NAME, type AgentOutcome, type EventData, type ToolKind } from '../core/events.ts'
import { LEAD } from '../core/fold.ts'
import type { RecordBody } from '../core/recording.ts'

export type Fields = Readonly<Record<string, unknown>>
export type SpawnFacts = { name?: string; subagentType?: string; description?: string; parentAgentId?: string }
export type StepUsage = {
  input_tokens: number; output_tokens: number; cache_read_input_tokens: number; cache_creation_input_tokens: number; model: string
}
export type Measure = { context: { tokens?: number; window: number; percent?: number }; cost?: { usd: number }; changed: readonly string[] }

const CONTROL = /[\p{Cc}\p{Cf}\p{Zl}\p{Zp}]/gu
const MAX_TOKENS = 1e12

/** Joins code points while they fit in `room` UTF-16 units, so a surrogate pair is never split. */
function fit(chars: readonly string[], room: number): string {
  let out = ''
  for (const c of chars) {
    if (out.length + c.length > room) break
    out += c
  }
  return out
}

/** Control and format characters become spaces, whitespace runs collapse, and the result is cut to `max` UTF-16 units, ending in an ellipsis when cut. */
export function cleanText(x: unknown, max: number): string {
  if (typeof x !== 'string') return ''
  const flat = x.replace(CONTROL, ' ').replace(/\s+/g, ' ').trim()
  return flat.length <= max ? flat : `${fit(Array.from(flat), max - 1)}…`
}

/** As cleanText, but a long path keeps its end, the part that tells files apart. */
export function cleanPath(x: unknown, max: number): string {
  const flat = cleanText(x, Number.MAX_SAFE_INTEGER)
  if (flat.length <= max) return flat
  const tail = fit(Array.from(flat).reverse(), max - 1)
  return `…${Array.from(tail).reverse().join('')}`
}

/** The same rule as memory previews in src/mcp/tools.ts (which a mod can't import): token-shaped runs are blanked. */
const SECRETISH = /(ghp_|gho_|github_pat_|sk-|sk_live_|xox[bap]-|AKIA)[A-Za-z0-9_-]{8,}|eyJ[A-Za-z0-9_-]{8,}\.[A-Za-z0-9_.-]+|[A-Za-z0-9+/=_-]{32,}/g

export const redact = (x: unknown): string => (typeof x === 'string' ? x.replace(SECRETISH, '[redacted]') : '')

const KINDS: Readonly<Record<string, ToolKind>> = {
  Read: 'read', NotebookRead: 'read',
  Edit: 'edit', MultiEdit: 'edit', Write: 'edit', NotebookEdit: 'edit',
  Bash: 'bash', PowerShell: 'bash', BashOutput: 'bash', KillShell: 'bash',
  Glob: 'search', Grep: 'search', LS: 'search',
  WebFetch: 'web', WebSearch: 'web',
  Agent: 'agent', Task: 'agent', SendMessage: 'agent',
}

export const toolKind = (tool: string): ToolKind => (Object.hasOwn(KINDS, tool) ? KINDS[tool]! : 'other')

/** The path or command a tool call is about, at most LIMITS.subject characters. Never arguments that hold content. */
export function toolSubject(tool: string, args: Fields): string {
  const max = LIMITS.subject
  switch (toolKind(tool)) {
    case 'read':
    case 'edit':
      return cleanPath(args.file_path ?? args.notebook_path, max)
    case 'bash':
      return cleanText(redact(args.command), max)
    case 'search':
      return cleanText(args.pattern ?? args.path, max)
    case 'web':
      return cleanText(redact(args.url ?? args.query), max)
    case 'agent':
      return cleanText(args.description ?? args.to ?? args.name, max)
    default:
      return ''
  }
}

const agentId = (x: unknown): string | null => (typeof x === 'string' && NAME.test(x) ? x : null)
const tokens = (x: unknown): number => (typeof x === 'number' && Number.isFinite(x) && x > 0 ? Math.min(Math.floor(x), MAX_TOKENS) : 0)

/** Who an event belongs to: the lead when the engine gave no agent id, the agent when the recorder saw it spawn, otherwise nobody (an engine fork). */
export function whoOf(id: unknown, seen: ReadonlySet<string>): string | null {
  if (id === undefined) return LEAD
  return typeof id === 'string' && seen.has(id) ? id : null
}

export function agentStarted(spawn: SpawnFacts, id: string): RecordBody<'agent.started'> | null {
  const agent = agentId(id)
  if (agent === null || agent === LEAD) return null
  return {
    type: 'agent.started',
    agent,
    data: {
      name: cleanText(spawn.name, 64),
      role: cleanText(spawn.subagentType, 64) || 'agent',
      description: cleanText(spawn.description, LIMITS.description),
      parent: agentId(spawn.parentAgentId) ?? LEAD,
    },
  }
}

const OUTCOMES: Readonly<Record<string, AgentOutcome>> = { answer: 'answer', aborted: 'aborted', refusal: 'failed', error: 'failed' }

export function agentFinished(reason: string, agent: string): RecordBody<'agent.finished'> {
  const outcome = Object.hasOwn(OUTCOMES, reason) ? OUTCOMES[reason]! : 'failed'
  return { type: 'agent.finished', agent, data: { outcome, reason: cleanText(reason, LIMITS.reason) } }
}

/** turn.step doesn't split cache writes by lifetime, so all of them go in the 5-minute bucket (spec section 7). */
export function agentUsage(usage: StepUsage, agent: string): RecordBody<'agent.usage'> {
  return {
    type: 'agent.usage',
    agent,
    data: {
      model: cleanText(usage.model, 80),
      input: tokens(usage.input_tokens),
      output: tokens(usage.output_tokens),
      cacheRead: tokens(usage.cache_read_input_tokens),
      cacheWrite5m: tokens(usage.cache_creation_input_tokens),
      cacheWrite1h: 0,
    },
  }
}

export function toolEvent(phase: 'start' | 'end', tool: string, args: Fields, agent: string, isError = false): RecordBody<'agent.tool'> {
  return {
    type: 'agent.tool',
    agent,
    data: { phase, tool: cleanText(tool, 80) || 'unknown', kind: toolKind(tool), subject: toolSubject(tool, args), isError },
  }
}

/** A delivered plain-text message, from session.send. A plugin's `{ agentId }` address is read too; a `{ sessionId }` one is not an agent. */
export function messageSent(to: unknown, text: unknown, agent: string): RecordBody<'message.sent'> | null {
  const address = typeof to === 'object' && to !== null && typeof (to as Fields).agentId === 'string' ? (to as Fields).agentId : to
  const name = cleanText(address, 64)
  if (name === '') return null
  return { type: 'message.sent', agent, data: { to: name, summary: cleanText(redact(text), LIMITS.summary) } }
}

/** A protocol SendMessage (`message` an object), from tool.call: the type and approval only, never reason or feedback text. */
export function protocolMessage(args: Fields, agent: string): RecordBody<'message.sent'> | null {
  const message = args.message
  if (typeof message !== 'object' || message === null || Array.isArray(message)) return null
  const fields = message as Fields
  const to = cleanText(args.to, 64)
  if (to === '') return null
  const kind = cleanText(fields.type, 40) || 'protocol'
  const approve = typeof fields.approve === 'boolean' ? ` approve: ${fields.approve ? 'yes' : 'no'}` : ''
  return { type: 'message.sent', agent, data: { to, summary: `[${kind}]${approve}` } }
}

export function sessionMeasure(m: Measure): RecordBody<'session.measure'> | null {
  if (!m.changed.includes('context') && !m.changed.includes('cost')) return null
  const data: EventData['session.measure'] = { contextWindow: tokens(m.context.window) }
  if (typeof m.context.tokens === 'number') data.contextTokens = tokens(m.context.tokens)
  if (typeof m.context.percent === 'number') data.contextPercent = Math.min(100, tokens(m.context.percent))
  const usd = m.cost?.usd
  if (typeof usd === 'number' && Number.isFinite(usd) && usd >= 0) data.costUsd = usd
  return { type: 'session.measure', data }
}
```

```ts
/** Per-session swarm state: which swarm this server is working in, and its folded state held between calls. */
import { readCurrent, writeCurrent } from '../core/log.ts'
import { SESSION_ID } from '../core/recording.ts'
import { advance, loadState, type Loaded } from '../core/snapshot.ts'
import { announceSwarm, publishCurrent, swarmOwner, uniqueSwarmId } from '../core/swarm.ts'
import { InputError } from './validate.ts'

const stamp = (d: Date): string => d.toISOString().replace(/[-:]/g, '').replace('T', '-').slice(0, 15)

export class Session {
  readonly root: string
  readonly #load: (root: string, id: string) => Loaded
  readonly #held = new Map<string, Loaded>()
  /** The swarm this server started or adopted. Other sessions in the same project may share `current`. */
  #mine: string | null = null
  /** True when this session started `#mine`. An adopted swarm of another session is never ended or renamed here. */
  #owned = false
  /** The Claude Code session this server serves, learned from the recorder's first omnis_record call. */
  #sessionId: string | null = null
  /** The swarm whose owner was last read from its log, so each swarm's log is read once per session id. */
  #ownerRead: string | null = null

  /** `load` is only replaced in tests, to count full loads. */
  constructor(root: string, load: (root: string, id: string) => Loaded = loadState) {
    this.root = root
    this.#load = load
  }

  get sessionId(): string | null {
    return this.#sessionId
  }

  /** Records which Claude Code session this server serves. The first valid id wins: one server process serves one session. */
  noteSession(id: string): void {
    if (this.#sessionId === null && SESSION_ID.test(id)) this.#sessionId = id
  }

  /** True when this session started the swarm it is in: in this process, or before a restart by the session id in the swarm's log. */
  get owned(): boolean {
    const id = this.#mine
    if (!this.#owned && id !== null && this.#sessionId !== null && this.#ownerRead !== id) {
      this.#ownerRead = id
      this.#owned = swarmOwner(this.root, id) === this.#sessionId
    }
    return this.#owned
  }

  /** The folded state of swarm `id`, loaded once and then advanced by whatever was appended since. Treat it as read-only. */
  state(id: string): Loaded {
    const held = this.#held.get(id)
    if (held === undefined) {
      const loaded = this.#load(this.root, id)
      this.#held.set(id, loaded)
      return loaded
    }
    advance(this.root, held)
    return held
  }

  hasEnded(id: string): boolean {
    return this.state(id).state.swarm.endedAt !== null
  }

  /** My live swarm. While I have none I adopt `current`: always when `adopt` is true, otherwise only if its log says this session started it. */
  mySwarm(adopt = true): string | null {
    if (this.#mine !== null && this.hasEnded(this.#mine)) this.letGo()
    if (this.#mine === null) {
      const c = readCurrent(this.root)
      if (c !== null && !this.hasEnded(c)) {
        const ours = this.#sessionId !== null && swarmOwner(this.root, c) === this.#sessionId
        if (adopt || ours) {
          this.#mine = c
          this.#owned = ours
          this.#ownerRead = this.#sessionId === null ? null : c
        }
      }
    }
    return this.#mine
  }

  /** Records that this session started swarm `id`. */
  begin(id: string): void {
    this.#mine = id
    this.#owned = true
    this.#ownerRead = id
  }

  /** Forgets the current swarm without ending it. */
  letGo(): void {
    this.#mine = null
    this.#owned = false
    this.#ownerRead = null
  }

  /** My live swarm, starting an implicit one if there is none: `session-<first 8 of the session id>`, or by time before the id is known. */
  swarmOrCreate(now: Date): string {
    const id = this.mySwarm()
    if (id !== null) return id
    const root = this.root
    const sid = this.#sessionId
    const idHint = sid !== null ? `session-${sid.slice(0, 8)}` : `session-${stamp(now)}`
    const current = readCurrent(root)
    const claimed = uniqueSwarmId(root, idHint)
    announceSwarm(root, claimed, { src: 'mcp', now, ...(sid !== null && { session: sid }) })
    if (current !== null && this.hasEnded(current)) {
      // current names an ended swarm: replace it, as an explicit init would
      writeCurrent(root, claimed)
      this.#mine = claimed
    } else {
      // Another session may publish first; then we adopt its swarm and don't own it.
      this.#mine = publishCurrent(root, claimed)
    }
    this.#owned = this.#mine === claimed
    this.#ownerRead = sid === null ? null : this.#mine
    return this.#mine
  }

  runningSwarm(): string {
    const id = this.mySwarm()
    if (id === null) throw new InputError('No swarm is running. Call omnis_swarm_init first.')
    return id
  }
}
```

```ts
/**
 * omnis_record: how the recorder mod's events reach the log (a mod can't write files).
 * Internal: the mod's tool.check guard refuses it to the model, but when mods are off it is
 * unguarded, so this checks everything itself (spec section 6). It builds each event's data
 * afresh from known fields, so nothing else the caller sends reaches the log.
 */
import { AGENT_OUTCOMES, LIMITS, NAME, TOOL_KINDS, makeEvent, serialise, type EventData } from '../../core/events.ts'
import { appendEvent } from '../../core/log.ts'
import { RECORDER_TYPES, RECORD_TOOL, SESSION_ID, type RecorderType } from '../../core/recording.ts'
import type { Args, ToolDef } from '../protocol.ts'
import type { ToolContext } from '../tools.ts'
import { InputError, reqEnum, reqString } from '../validate.ts'

const CONTROL = /[\p{Cc}\p{Cf}\p{Zl}\p{Zp}]/u
const MAX_COUNT = 1e12
const MAX_USD = 1e9
const FAILED = 'Could not record the event in .omnis-swarm/ (see the server log).'

const isObj = (x: unknown): x is Args => typeof x === 'object' && x !== null && !Array.isArray(x)

/** Text that may be empty unless `nonEmpty`, at most `max` characters, with no control or formatting characters. */
function text(d: Args, key: string, max: number, nonEmpty = false): string {
  const v = d[key]
  if (typeof v !== 'string' || v.length > max || CONTROL.test(v) || (nonEmpty && v.trim() === '')) {
    throw new InputError(`data.${key} must be ${nonEmpty ? 'non-empty ' : ''}text of at most ${max} characters with no control characters`)
  }
  return v
}

function count(d: Args, key: string, max = MAX_COUNT): number {
  const v = d[key]
  if (typeof v !== 'number' || !Number.isSafeInteger(v) || v < 0 || v > max) throw new InputError(`${key} must be a whole number from 0 to ${max}`)
  return v
}

function oneOf<T extends string>(d: Args, key: string, values: readonly T[]): T {
  const v = d[key]
  if (typeof v !== 'string' || !(values as readonly string[]).includes(v)) throw new InputError(`data.${key} must be one of: ${values.join(', ')}`)
  return v as T
}

function agentName(d: Args, key: string): string {
  const v = d[key]
  if (typeof v !== 'string' || !NAME.test(v)) throw new InputError(`${key} must be an agent id (letters, digits, . _ -, at most 64)`)
  return v
}

/** The ts the mod stamped: an ISO-8601 UTC time with milliseconds, exactly as Date.toISOString writes it. */
function isoTime(v: unknown): string {
  if (typeof v !== 'string' || v.length > 32 || Number.isNaN(Date.parse(v)) || new Date(v).toISOString() !== v) {
    throw new InputError('ts must be an ISO-8601 UTC time with milliseconds')
  }
  return v
}

function dataFor(type: RecorderType, d: Args): EventData[RecorderType] {
  switch (type) {
    case 'agent.started':
      return { name: text(d, 'name', 64), role: text(d, 'role', 64), description: text(d, 'description', LIMITS.description), parent: agentName(d, 'parent') }
    case 'agent.finished':
      return { outcome: oneOf(d, 'outcome', AGENT_OUTCOMES), ...(d.reason !== undefined && { reason: text(d, 'reason', LIMITS.reason) }) }
    case 'agent.usage':
      return {
        model: text(d, 'model', 80),
        input: count(d, 'input'), output: count(d, 'output'), cacheRead: count(d, 'cacheRead'),
        cacheWrite5m: count(d, 'cacheWrite5m'), cacheWrite1h: count(d, 'cacheWrite1h'),
      }
    case 'agent.tool': {
      const isError = d.isError
      if (typeof isError !== 'boolean') throw new InputError('data.isError must be true or false')
      return {
        phase: oneOf(d, 'phase', ['start', 'end'] as const), tool: text(d, 'tool', 80, true),
        kind: oneOf(d, 'kind', TOOL_KINDS), subject: text(d, 'subject', LIMITS.subject), isError,
      }
    }
    case 'message.sent':
      return { to: text(d, 'to', 64, true), summary: text(d, 'summary', LIMITS.summary) }
    case 'session.measure': {
      const usd = d.costUsd
      if (usd !== undefined && (typeof usd !== 'number' || !Number.isFinite(usd) || usd < 0 || usd > MAX_USD)) {
        throw new InputError(`data.costUsd must be a number from 0 to ${MAX_USD}`)
      }
      return {
        contextWindow: count(d, 'contextWindow'),
        ...(d.contextTokens !== undefined && { contextTokens: count(d, 'contextTokens') }),
        ...(d.contextPercent !== undefined && { contextPercent: count(d, 'contextPercent', 100) }),
        ...(usd !== undefined && { costUsd: usd }),
      }
    }
  }
}

export function createRecordTools(ctx: ToolContext): ToolDef[] {
  const { root, session } = ctx
  const tool: ToolDef = {
    name: RECORD_TOOL,
    description: 'Internal to the omnis-swarm plugin: the recorder mod appends one observed event to the swarm log. Calls from the model are refused.',
    inputSchema: {
      type: 'object',
      properties: {
        sessionId: { type: 'string', pattern: SESSION_ID.source },
        ts: { type: 'string', maxLength: 32 },
        type: { type: 'string', enum: [...RECORDER_TYPES] },
        agent: { type: 'string', pattern: NAME.source },
        data: { type: 'object' },
        dropped: { type: 'integer', minimum: 0 },
      },
      required: ['sessionId', 'ts', 'type', 'data'],
      additionalProperties: false,
    },
    handler: args => {
      const type = reqEnum(args, 'type', RECORDER_TYPES)
      const sessionId = reqString(args, 'sessionId', 64, SESSION_ID)
      const ts = isoTime(args.ts)
      const agent = args.agent === undefined ? undefined : agentName(args, 'agent')
      if (!isObj(args.data)) throw new InputError('data must be an object')
      const dropped = args.dropped === undefined ? 0 : count(args, 'dropped')
      const data = dataFor(type, args.data)
      if (dropped > 0) Object.assign(data, { dropped })
      const now = new Date(ts)
      // Checked before anything touches the disk, so a refused call writes nothing.
      const probe = makeEvent({ type, swarm: 'probe', src: 'recorder', data, ...(agent !== undefined && { agent }), now })
      try {
        serialise(probe)
      } catch {
        throw new InputError(`the event is over ${LIMITS.line} bytes`)
      }
      session.noteSession(sessionId)
      const swarm = session.swarmOrCreate(now)
      if (!appendEvent(root, { ...probe, swarm })) throw new Error('append failed')
      return { text: 'ok' }
    },
  }
  return [{
    ...tool,
    // Anything but a bad-input error gets a fixed message; the detail (which may hold paths) goes to stderr only.
    handler: args => {
      try {
        return tool.handler(args)
      } catch (err) {
        if (err instanceof InputError) throw err
        process.stderr.write(`omnis: ${RECORD_TOOL} failed: ${err instanceof Error ? err.message : String(err)}\n`)
        throw new Error(FAILED)
      }
    },
  }]
}
```

```ts
/** The recorder's in-flight cap and drop counter (spec section 6). Pure and mod-safe; node:test covers it. */
import { MAX_IN_FLIGHT } from '../core/recording.ts'

export class Outbox {
  readonly limit: number
  inFlight = 0
  /** Events lost since the last call that got a slot. */
  dropped = 0

  constructor(limit = MAX_IN_FLIGHT) {
    this.limit = limit
  }

  /** Reserves a slot and hands back the drop count to carry on this call (then cleared), or null when full (the event is counted as dropped). */
  take(): number | null {
    if (this.inFlight >= this.limit) {
      this.dropped++
      return null
    }
    this.inFlight++
    const carried = this.dropped
    this.dropped = 0
    return carried
  }

  /** A call settled. A failed one counts itself and whatever it carried as dropped. */
  settle(ok: boolean, carried: number): void {
    this.inFlight = Math.max(0, this.inFlight - 1)
    if (!ok) this.dropped += 1 + carried
  }

  /** Counts events lost before they could be sent. */
  lose(n = 1): void {
    this.dropped += n
  }
}
```

```ts
/**
 * The recorder (spec section 6): observe-only hooks that turn Claude Code events into log events
 * and send each, fire and forget, to the server's internal omnis_record tool. Every hook calls
 * next once and returns its result unchanged; its own work is wrapped so a failure only loses an event.
 */
import { atom, read, update } from 'claude-code'
import type { EngineInterface, On } from 'claude-code'
import { INTERNAL_TOOL, RECORD_TOOL, type RecordBody } from '../core/recording.ts'
import { Outbox } from './outbox.ts'
import { connectServer } from './server.ts'
import {
  agentFinished, agentStarted, agentUsage, messageSent, protocolMessage, sessionMeasure, toolEvent, whoOf, type Fields,
} from './record-events.ts'

const MAX_SEEN = 1000
const seenAtom = atom({ plugin: 'omnis-swarm', key: 'seen' } as const, [] as string[])
const droppedAtom = atom({ plugin: 'omnis-swarm', key: 'dropped' } as const, 0)

/** Module state. A hot reload starts it over; session.start restores the seen agents and the drop count from $.state. */
const rec = {
  sessionId: null as string | null,
  server: null as string | null,
  seen: new Set<string>(),
  outbox: new Outbox(),
}

function saveDropped($: EngineInterface): void {
  update($, droppedAtom, () => rec.outbox.dropped).catch(() => {})
}

function remember($: EngineInterface, id: string): void {
  rec.seen.add(id)
  for (const old of rec.seen) {
    if (rec.seen.size <= MAX_SEEN) break
    rec.seen.delete(old)
  }
  update($, seenAtom, () => [...rec.seen]).catch(() => {})
}

/** Fire and forget: never awaited, never throws. Arguments are plain data and the time is the hook's own. */
function send($: EngineInterface, body: RecordBody | null): void {
  if (body === null) return
  const { sessionId, server } = rec
  if (sessionId === null || server === null) return
  const carried = rec.outbox.take()
  if (carried === null) {
    saveDropped($)
    return
  }
  const args = { sessionId, ts: new Date(Date.now()).toISOString(), ...body, ...(carried > 0 && { dropped: carried }) }
  if (carried > 0) saveDropped($)
  const failed = (): void => {
    rec.outbox.settle(false, carried)
    saveDropped($)
  }
  try {
    $.mcp.call(server, RECORD_TOOL, args).then(result => (result.isError ? failed() : rec.outbox.settle(true, carried)), failed)
  } catch {
    failed()
  }
}

/** Runs recorder work that must never reach the session: a throw only costs the event. */
function safely($: EngineInterface, work: () => void): void {
  try {
    work()
  } catch {
    rec.outbox.lose()
    saveDropped($)
  }
}

async function start($: EngineInterface): Promise<void> {
  rec.sessionId = await $.session.id()
  rec.server = await connectServer($)
  rec.outbox.dropped = Math.max(rec.outbox.dropped, await read($, droppedAtom))
  for (const id of await read($, seenAtom)) rec.seen.add(id)
  // Agents started before a reload (or before the plugin loaded) still get their agent.started, once.
  for (const agent of await $.agent.list()) {
    if (rec.seen.has(agent.id)) continue
    const body = agentStarted({ name: agent.name, subagentType: agent.type, description: agent.description, parentAgentId: agent.parentId }, agent.id)
    if (body === null) continue
    remember($, agent.id)
    send($, body)
  }
}

export function registerRecorder(on: On): void {
  on('session.start', async ($, e, next) => {
    const result = await next(e)
    try {
      await start($)
    } catch {
      // Recording stays off for this session; the session itself is untouched.
    }
    return result
  })

  on('agent.spawn', async ($, e, next) => {
    const result = await next(e)
    safely($, () => {
      const id = result.deny === undefined ? result.agentId : undefined
      if (typeof id !== 'string' || rec.seen.has(id)) return
      const body = agentStarted(e, id)
      if (body === null) return
      remember($, id)
      send($, body)
    })
    return result
  }).catch((_$, e, next) => next(e))

  on('tool.call', async ($, e, next) => {
    const tool = String(e.tool)
    const args = e as unknown as Fields
    let agent: string | null = null
    safely($, () => {
      agent = INTERNAL_TOOL.test(tool) ? null : whoOf(args.agentId, rec.seen)
      if (agent !== null) send($, toolEvent('start', tool, args, agent))
    })
    const result = await next(e)
    const who: string | null = agent
    if (who !== null) {
      safely($, () => {
        const failed = result.isError === true || result.deny !== undefined
        send($, toolEvent('end', tool, args, who, failed))
        // Plain-text SendMessage is recorded from session.send; protocol payloads raise none, so they come from here.
        if (tool === 'SendMessage' && !failed) send($, protocolMessage(args, who))
      })
    }
    return result
  }).catch((_$, e, next) => next(e))

  on('turn.step', async function* ($, e, next) {
    const result = yield* next(e)
    safely($, () => {
      const agent = whoOf(e.agentId, rec.seen)
      if (agent !== null && result.usage !== null) send($, agentUsage(result.usage, agent))
    })
    return result
  })

  on('turn.complete', async ($, e, next) => {
    const result = await next(e)
    safely($, () => {
      if (e.agentId === undefined) return
      const agent = whoOf(e.agentId, rec.seen)
      if (agent !== null) send($, agentFinished(e.reason, agent))
    })
    return result
  })

  on('session.send', async ($, e, next) => {
    const result = await next(e)
    safely($, () => {
      if (e.origin.kind !== 'model' || result.isDelivered !== true) return
      const agent = whoOf(e.agentId, rec.seen)
      if (agent !== null) send($, messageSent(e.to, e.text, agent))
    })
    return result
  }).catch((_$, e, next) => next(e))

  on('session.measure', async ($, e, next) => {
    const result = await next(e)
    safely($, () => send($, sessionMeasure(e)))
    return result
  })
}
```
